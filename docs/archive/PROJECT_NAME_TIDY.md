## Original options and safeguards — historical

There is **no edit form**. The app can change a Project's nudgeable flag and HPC
keep date, but not its name or descriptions. Choose one:

- a small admin edit feature, or
- a reviewed, scripted update. It must append a `reconciliationHistory` entry
  with the before and after values, matching how the registrations were recorded.

Either way:

- Leave `safeName` and `path` alone: they identify the directory on HPC.
- Leave `owner`, `storage.*` and `archiveMigration.*` alone too.
- Draft all 22 new names and descriptions in one list, have George approve it,
  then apply them together.

Registration details for every Project are in
[OUTCOMES.md](batches/2026-10-16/registration-production-2026-10-22/OUTCOMES.md).
